Reference series

Three series power the transforms everywhere: population (per-person), the GDP deflator (real terms) and nominal GDP (%-of-GDP). If a transformed number looks wrong, check these first.

How to verify a number
  1. Find the indicator above and expand it, then open its API endpoint — that is the same address the pipeline called, at the source, not a copy we host.
  2. Find the year you care about and compare it with the raw values in the expanded row. Monthly and quarterly sources are averaged to one value per year, so compare the annual figure where the source publishes one.
  3. Cross-check the source release link for context — definitions, revisions and footnotes live there.
  4. Or reproduce the whole bundle: clone the repo and run python ingest/ingest.py --dry-run. It fetches everything fresh from the sources and reports what it got. Nothing is computed at ingest beyond collapsing to years — every transform happens in your browser, from the values on this page.

Found a mismatch? The bundle records when it was fetched — sources revise their own history, which is normal for official statistics. If the current release disagrees with the bundle, a weekly refresh will pick it up; anything else is a bug worth reporting.
