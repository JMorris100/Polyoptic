How to verify a number

Four steps, none of which require taking our word for anything.

  1. Open the indicator below and hit its API endpoint — the same address the pipeline called, at the source, not a copy we host.
  2. Compare the year you care about with the raw values in the expanded row. Monthly and quarterly sources are averaged to one value per year, so compare against the annual figure where the source publishes one.
  3. Read the source release for context. Definitions, revisions and footnotes live there, and the caveat badges on each row point at what to look for.
  4. Or reproduce the whole thing. Clone the repo and run python ingest/ingest.py --dry-run: it fetches everything fresh and reports what it got. Nothing is computed at ingest beyond collapsing to years — every transform happens in your browser, from the values on this page.

Found a mismatch? The bundle records when it was fetched, and sources revise their own history — that is normal for official statistics. If the current release disagrees with the bundle, the weekly refresh will pick it up. Anything else is a bug, and worth telling us about.

Reference series

Three series power every transform on the site: population behind per person, the GDP deflator behind real terms, and nominal GDP behind % of GDP. If a transformed number looks wrong, check these first — a transform is only ever as good as its denominator.

Indicator search

Filter down, then expand a row to verify it. Badges name the caveat that applies — Discontinued Definition changed Partial period Provisional Sub-UK coverage — so a marked row tells you what to go and read, rather than only that something exists to read.
