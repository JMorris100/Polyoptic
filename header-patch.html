UK official statistics

Every UK statistic, made comparable.

Government publishes thousands of figures across dozens of departments, in different units, on different calendars, for different parts of the country. Polyoptic brings them together and lets you rebase, adjust for inflation, compare and map them — and tells you when two numbers aren't measuring the same thing.

Explorer margin

The explorer shell is running edge to edge. Give it the same gutter as the rest of the site and it stops looking like a different application: 
.shell{
  max-width: 1600px;
  margin: 0 auto;
  padding: 24px 32px 80px;   /* was flush to the viewport edge */
  display: grid;
  grid-template-columns: 300px 1fr;
  gap: 22px;                 /* breathing room between sidebar and chart */
  align-items: start;
}

/* the sidebar needs to stop touching the header too */
.panel{ border: 1px solid var(--rule); border-radius: 2px; }

@media (max-width: 1000px){
  .shell{ grid-template-columns: 1fr; padding: 20px 20px 60px; }
}
